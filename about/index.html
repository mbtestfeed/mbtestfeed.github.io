About

Note

This is the Gho-Static starter site’s default page. If you’re not viewing it on gho-static.com or mbtestfeed.github.io, whoever generated this site hasn’t replaced it, so the site is likely unaffiliated with mbtestfeed or Gho-Static, who take no responsibility for this website’s content.

Gho-Static is a project that’s primarily built to satisfy the needs of one person - myself. There’s enough static generators out there in the world that I could have really just used one of those, but I felt like building one myself - partially for learning, partially because it’s an interesting (yet reasonably well defined) challenge, and partially for the joy of building something. There’s nothing particularly wrong with any of the other static site generators - and if I’m being honest, you should probably just pick one of the more popular ones if you’re in the market. (I hear good things about Hugo..?)

I chose Go as the baseline language behind it because… I like Go? Does there need to be much more reason? It’s a well supported language, which makes a very nice compromise between developer experience and speed.

Gho-Static fits in a slightly weird space (like most static website generators), in that if you understand it well enough to use it then you probably don’t need it. They’re technical enough that they’re not the most inviting to non-technical people, but not so complicated that most developers couldn’t take a decent crack at them or write a dynamic website that fits their needs better. But I was looking at publishing a few sites for myself and my different projects (which we’ll see if they ever go anywhere - I’m a chronic project starter, less so a project finisher…), so I thought this seemed like a way to make that a little easier to manage.

The vision is that you can write markdown files, maybe tinker with a little CSS, add JavaScript (if you’re really daring), run a couple of commands and… Hey! You’ve got a new website online! Nothing fancy - just some brochureware, maybe a blog and an image gallery/portfolio. That’s what you need out of a website most of the time anyway, right?

There’s a certain sort of beauty in keeping your website simple, isn’t there? There’s practically nothing there to hack - which is increasingly a concern in the age of AI. Upkeep is minimal, load times are fast, SEO is decent out of the box - your time is precious and your web presence is valuable.

But at the same time it’s interesting to see just how much functionality and usefulness you can fit into a “simple” idea, and we’ll see just how far that I get.
